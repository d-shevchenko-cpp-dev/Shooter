# Рефакторинг Projectile и LauncherWeapon

## Обзор изменений

Проведен комплексный рефакторинг системы снарядов и гранатометов в проекте ShootThemUp для улучшения архитектуры, читаемости кода и расширяемости.

## Основные улучшения

### 1. STUProjectile - Класс снаряда

#### Новые возможности:
- **Структура настроек FSTUProjectileData** - централизованное управление параметрами снаряда
- **Система урона** - автоматическое применение урона при попадании
- **Обработка коллизий** - правильная настройка коллизий и обработка попаданий
- **Настраиваемые параметры**:
  - Начальная и максимальная скорость
  - Время жизни
  - Радиус коллизии
  - Урон и тип урона
  - Отскок и коэффициент отскока

#### Архитектурные улучшения:
- Разделение логики инициализации компонентов
- Применение настроек через отдельный метод
- Обработка попаданий с предотвращением самопопадания
- Правильная очистка ресурсов

### 2. STULauncherWeapon - Класс гранатомета

#### Новые возможности:
- **Структура настроек FSTULauncherWeaponData** - настройки гранатомета
- **Улучшенная логика создания снарядов** - правильный спавн с владельцем и инстигатором
- **Разделение ответственности** - отдельные методы для спавна и конфигурации
- **Улучшенное логирование** - детальная информация о процессе стрельбы

#### Архитектурные улучшения:
- Убраны TODO комментарии и временные заглушки
- Улучшена обработка ошибок
- Правильная передача владельца снаряда
- Централизованные настройки через структуру данных

## Структура данных

### FSTUProjectileData
```cpp
struct FSTUProjectileData {
    float InitialSpeed = 2000.0f;     // Начальная скорость
    float MaxSpeed = 2000.0f;         // Максимальная скорость
    float LifeSpan = 5.0f;            // Время жизни
    float CollisionRadius = 5.0f;     // Радиус коллизии
    float DamageAmount = 50.0f;       // Урон
    TSubclassOf<UDamageType> DamageType; // Тип урона
    bool bShouldBounce = false;       // Включить отскок
    float Bounciness = 0.3f;          // Коэффициент отскока
};
```

### FSTULauncherWeaponData
```cpp
struct FSTULauncherWeaponData {
    float ProjectileSpeed = 2000.0f;      // Скорость снаряда
    float ProjectileRadius = 5.0f;        // Радиус снаряда
    float ProjectileLifeSpan = 5.0f;      // Время жизни снаряда
    float ProjectileDamage = 100.0f;      // Урон снаряда
    bool bProjectileBounce = false;       // Отскок снарядов
    float ProjectileBounciness = 0.3f;    // Коэффициент отскока
};
```

## Архитектурные принципы

### 1. Разделение ответственности
- **STUProjectile**: отвечает за физику, движение и урон снаряда
- **STULauncherWeapon**: отвечает за создание и настройку снарядов

### 2. Централизация настроек
- Все параметры вынесены в отдельные структуры данных
- Настройки доступны в редакторе через UPROPERTY
- Легкая настройка без изменения кода

### 3. Обработка ошибок
- Проверки на валидность указателей
- Детальное логирование всех операций
- Graceful handling ошибок

### 4. Расширяемость
- Легко добавлять новые типы снарядов
- Простое изменение параметров через структуры данных
- Возможность наследования и переопределения

## Преимущества рефакторинга

1. **Читаемость кода** - четкое разделение логики и настроек
2. **Поддерживаемость** - централизованные настройки и модульная архитектура
3. **Расширяемость** - легкое добавление новых типов оружия и снарядов
4. **Производительность** - оптимизированная инициализация и управление памятью
5. **Отладка** - детальное логирование всех операций
