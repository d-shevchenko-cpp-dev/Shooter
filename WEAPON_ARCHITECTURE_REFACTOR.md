# Рефакторинг системы оружия - Новая архитектура

## Обзор изменений

Проведен рефакторинг системы оружия для улучшения расширяемости и разделения ответственности между классами.

## Новая архитектура

```
ASTUBaseWeapon (Абстрактный базовый класс)
├── ASTURiffleWeapon (Автоматическая винтовка)
└── ASTULauncherWeapon (Гранатомет/ракетница)
    ├── Будущие классы:
    ├── ASTUPistolWeapon (Пистолет)
    ├── ASTUSniperWeapon (Снайперская винтовка)
    └── ASTUShotgunWeapon (Дробовик)
```

## Изменения в ASTUBaseWeapon

### Что осталось в базовом классе:
- Общие компоненты (WeaponMesh, DamageComponent, DebugManager)
- Данные оружия (FSTUWeaponData)
- Утилитарные методы:
  - `CanFire()` - проверка возможности стрельбы
  - `IsValidForShooting()` - валидация оружия
  - `GetShootDirection()` - расчет направления с разбросом
  - `IsHeadshot()` - определение headshot
  - `PerformLineTrace()` - линейный трейсинг
  - `ApplyDamageToTarget()` - применение урона
  - `StartAutomaticFire()` / `StopAutomaticFire()` - управление таймерами

### Что стало виртуальным (пустые методы):
- `Fire()` - начало стрельбы
- `StopFire()` - остановка стрельбы
- `MakeShot()` - выполнение выстрела

## Изменения в ASTURiffleWeapon

### Реализованная логика:
- **Fire()**: Проверка возможности стрельбы → первый выстрел → запуск автоматической стрельбы
- **StopFire()**: Остановка автоматической стрельбы
- **MakeShot()**: Полная логика стрельбы с трейсингом и нанесением урона

### Особенности:
- Автоматическая стрельба с настраиваемым интервалом
- Линейный трейсинг от дула оружия к цели
- Учет разброса и модификаторов здоровья
- Обработка headshot'ов
- Отладочная информация

## Изменения в ASTULauncherWeapon

### Текущая реализация:
- **Fire()**: Одиночный выстрел (гранатометы стреляют по одному)
- **StopFire()**: Заглушка (гранатометы не требуют остановки)
- **MakeShot()**: Заглушка с TODO для будущей реализации

### Планируемые расширения:
- `ProjectileClass` - класс снаряда
- `LaunchForce` - сила запуска
- `ProjectileSpawnSocket` - сокет спавна снаряда
- `bUseGravity` - использование гравитации

## Преимущества новой архитектуры

1. **Разделение ответственности**: Каждый класс отвечает за свою логику стрельбы
2. **Расширяемость**: Легко добавлять новые типы оружия
3. **Переиспользование**: Общая логика остается в базовом классе
4. **Гибкость**: Каждый тип оружия может иметь уникальную логику
5. **Читаемость**: Код более структурирован и понятен

## Будущие возможности

### Типы оружия для добавления:
- **Пистолет**: Одиночные выстрелы, быстрая перезарядка
- **Снайперская винтовка**: Высокая точность, медленная стрельба, большой урон
- **Дробовик**: Множественные пули, короткая дистанция, высокий разброс
- **Пулемет**: Очень высокая скорострельность, нагрев ствола

### Дополнительные возможности:
- Система патронов и перезарядки
- Модификаторы оружия (глушители, прицелы)
- Различные типы боеприпасов
- Анимации стрельбы и перезарядки
- Эффекты (вспышки, дым, звуки)

## Совместимость

Все существующие Blueprint классы, наследующие от BaseWeapon, будут продолжать работать, но потребуют обновления для использования новой архитектуры.
