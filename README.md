# ShootThemUp

Игра ShootThemUp, разработанная на Unreal Engine 4. Это проект шутера от третьего лица с системой здоровья, оружия и урона.

## Описание проекта

ShootThemUp - это игра в жанре шутера от третьего лица, где игрок управляет персонажем, который может двигаться, стрелять из оружия и получать урон. Проект демонстрирует реализацию основных игровых систем в Unreal Engine 4.

## Основные возможности

- **Система движения**: Персонаж может двигаться, бегать и прыгать
- **Система здоровья**: Автоматическое восстановление здоровья, обработка смерти
- **Система оружия**: Стрельба с трейсингом, поддержка headshot'ов
- **Система урона**: Централизованная система нанесения и получения урона
- **HUD**: Отображение прицела и игрового интерфейса
- **Отладочные инструменты**: Визуализация трейсинга и тестовые акторы урона

## Архитектура проекта

### Основные классы

#### ASTUBaseCharacter
Базовый класс персонажа, который предоставляет:
- Движение и управление камерой
- Систему здоровья с автоматическим восстановлением
- Компонент оружия
- Обработку урона от падения

#### ASTUBaseWeapon
Базовый класс оружия с функциональностью:
- Стрельба с линейным трейсингом
- Нанесение урона при попадании
- Поддержка headshot'ов с множителем урона
- Отладочная визуализация трейсинга

#### USTUHealthComponent
Компонент здоровья с возможностями:
- Управление здоровьем персонажа
- Автоматическое восстановление здоровья
- События изменения здоровья и смерти
- Валидация параметров здоровья

#### USTUDamageComponent
Компонент для нанесения урона:
- Централизованная система нанесения урона
- Поддержка различных типов урона
- Интеграция с системой урона Unreal Engine

### Система урона

Проект включает комплексную систему урона с несколькими типами:

- **USTUWeaponDamageType**: Базовый тип урона от оружия
- **USTUFireDamageType**: Тип урона от огня
- **USTUIceDamageType**: Тип урона от льда

### Компоненты движения

#### USTUCharacterMovementComponent
Расширенный компонент движения с поддержкой:
- Модификатора скорости бега
- Интеграции с системой бега персонажа

### UI и HUD

#### ASTUGameHUD
HUD для отображения:
- Прицела в центре экрана
- Игрового интерфейса

## Настройка и использование

### Настройка персонажа

1. Создайте Blueprint на основе `ASTUBaseCharacter`
2. Настройте компоненты:
   - `HealthComponent`: Максимальное здоровье, параметры лечения
   - `WeaponComponent`: Класс оружия, точка прикрепления
3. Настройте анимацию смерти в `DeathAnimMontage`

### Настройка оружия

1. Создайте Blueprint на основе `ASTUBaseWeapon`
2. Настройте параметры:
   - `DamageAmount`: Базовый урон
   - `HeadshotMultiplier`: Множитель для headshot'ов
   - `MaxRange`: Максимальная дальность стрельбы
   - `HeadBoneName` и `NeckBoneName`: Кости для headshot'ов

### Настройка системы урона

1. Используйте `USTUDamageComponent` для нанесения урона
2. Создайте собственные типы урона, наследующие от `UDamageType`
3. Настройте параметры урона в редакторе

## Управление

- **WASD**: Движение
- **Мышь**: Поворот камеры
- **Пробел**: Прыжок
- **Shift**: Бег (удерживать)
- **ЛКМ**: Стрельба

## Отладочные возможности

### Визуализация трейсинга

Включите `bDrawDebugTrace` в настройках оружия для отображения:
- Линии трейсинга
- Сферы в точке попадания

### Тестовый актор урона

`ASTUDevDamageActor` позволяет тестировать радиальный урон:
- Настройте радиус и количество урона
- Выберите тип урона
- Актор будет наносить урон каждую секунду

## Технические детали

### Система трейсинга

Оружие использует линейный трейсинг от дула до точки прицеливания камеры:
- Игнорирует владельца оружия
- Поддерживает отладочную визуализацию
- Обрабатывает попадания в кости

### Система здоровья

- Автоматическое восстановление с настраиваемой задержкой
- События для интеграции с Blueprint
- Валидация параметров в конструкторе

### Система урона

- Интеграция с системой урона Unreal Engine
- Поддержка различных типов урона
- Централизованная обработка нанесения урона

## Расширение проекта

### Добавление нового оружия

1. Создайте класс, наследующий от `ASTUBaseWeapon`
2. Переопределите `Fire()` для кастомной логики
3. Настройте параметры в Blueprint

### Добавление новых типов урона

1. Создайте класс, наследующий от `UDamageType`
2. Настройте свойства в конструкторе
3. Используйте в компонентах урона

### Добавление новых компонентов

1. Создайте класс, наследующий от `UActorComponent`
2. Добавьте необходимую функциональность
3. Интегрируйте с существующими системами
